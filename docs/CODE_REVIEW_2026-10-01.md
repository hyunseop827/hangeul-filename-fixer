# 코드 리뷰 기록 (2026-10-01)

`5044478` 기준 전체 코드를 리뷰하고 정리한 기록입니다. Claude Code(Claude Opus 5.5)의 다중 에이전트 리뷰로 진행했습니다.
작업 방식은 [AI_DEVELOPMENT.md](AI_DEVELOPMENT.md), 변경 목록은 [v1.1.0 릴리스 노트](https://github.com/hyunseop827/hangeul-filename-fixer/releases/tag/v1.1.0)에 있습니다.

## 진행 방식

| 단계 | 내용 | 규모 |
| --- | --- | --- |
| 1차 리뷰 | 6개 관점 리뷰 + 발견마다 검증 2개(재현 / 의도·가치) + 누락 점검 | 에이전트 19개, 발견 114건 |
| 수정 | 검증을 통과한 항목 중 가치 있는 것만 반영 | |
| 2차 리뷰 | 수정한 코드를 4개 관점으로 다시 리뷰 + 반박 검증 + 변이 테스트 | 에이전트 12개, 발견 15건 |
| 실행 검증 | 아래 "검증 결과" 참고 | |

리뷰 관점: 파일명 로직, Electron 보안, 화면·UX, 빌드·의존성·설정, 문서 정확성, 중복·단순화.

## 주요 발견과 조치

### 실제 버그

| 문제 | 조치 |
| --- | --- |
| 확장자에 Windows 금지 문자, 끝 마침표·공백이 남음 (`file.`, `a.txt `, `a.b\|c`) | 확장자도 정리하고 전체 이름 끝의 마침표·공백 제거 |
| `con.tar.gz`, `nul .tar.gz`, `COM¹` 같은 예약 이름 누락 | 첫 마침표 앞부분으로 판단, 위첨자 포함 |
| 이름 바꾸기에서 확장자를 입력하면 두 번 붙음, `.이름`은 숨김 파일이 됨 | 입력 정리 후 같은 확장자 제거, 앞 마침표 제거 |
| exFAT에서 확인 실패 후 사본과 `._` 파일이 남음 | 처음 쓴 NFC 경로로 삭제 |
| 모든 실패를 "NFC로 보존하지 못했습니다"로 표시 | 오류 코드별 한국어 메시지 |
| 폴더를 넣으면 "확인하는 중"에서 멈춤 | 원인 안내 문구 |
| 변환 중 다시 누르면 중복 사본, 다른 파일로 바꾸면 엉뚱한 결과 표시 | 변환 중 버튼·입력 잠금, 완료 후 다시 미리보기 |
| 기본 창 크기에서 변환 버튼과 결과가 화면 밖 | 창 높이와 여백 조정 (자동 측정으로 확인) |
| 드래그한 경로가 항상 NFD라 NFC 파일도 깨진 이름으로 표시 | main이 폴더를 읽어 저장된 원본 이름을 돌려줌 |
| 파일명에 `\`가 있으면 저장 위치를 잘못 계산 | macOS 경로는 `/`로만 분리 |
| 같은 이름의 대상 없는 심볼릭 링크가 있으면 링크를 따라가 다른 곳에 씀 | `COPYFILE_EXCL` + `lstat`으로 이름 확인 |

### 보안

| 문제 | 조치 |
| --- | --- |
| 사본이 다운로드 보안 표시(quarantine)를 잃어 Gatekeeper 우회 | `xattr`로 속성 복사 (읽기 전용 파일 포함) |
| renderer 샌드박스 꺼짐 | `sandbox: true` |
| 새 창·다른 URL 이동 허용, CSP 없음 | 차단 + CSP |
| 배포 앱이 `ELECTRON_RENDERER_URL`로 임의 페이지를 띄움 | 배포 앱에서는 무시 |
| Electron fuses 미설정 (`ELECTRON_RUN_AS_NODE` 등) | fuses 설정 |
| `npm audit` 16건, 배포되는 Electron 42.4.0 포함 | `npm audit fix`로 15건 해결, Electron 42.11.10 |

### 정리

- 개발 의존성 `concurrently`, `wait-on` 제거 → `scripts/dev.mjs` (패키지 19개 감소)
- 화면에서 쓰지 않던 여러 파일 처리 코드 제거, IPC를 파일 하나 기준으로 단순화
- 화면과 main에 중복된 파일명 규칙을 `electron/naming.ts` 하나로 통합
- 깨진 `npm run dev` 스크립트 제거, 빈 `dependencies` 제거, `private`·`author`·`repository`·`engines` 추가
- TypeScript 엄격 옵션, 빌드 시 화면 타입 검사, 테스트 추가

## 반영하지 않은 항목

| 제안 | 반영하지 않은 이유 |
| --- | --- |
| 저장 위치의 파일 시스템 종류(exFAT 등)를 감지해서 따로 처리 | 저장 후 다시 읽어 확인하는 방식이 더 단순하고 확실합니다. 대신 오류 문구와 README로 안내합니다. |
| NFC 확인에서 파일을 못 찾으면 실패 처리 | 네트워크 볼륨 등에서 정상 사본을 지울 위험이 있어 현재 동작을 유지했습니다. |
| 이름 바꾸기에서 확장자처럼 보이지 않는 꼬리 처리 (`v1.0 최종본`) | 휴리스틱이 정상 확장자를 망가뜨릴 수 있고, 결과 이름을 미리 보여주므로 유지했습니다. |
| 255자 넘는 이름 자르기 | 거의 일어나지 않습니다. "파일명이 너무 깁니다" 안내만 추가했습니다. |
| 외장 드라이브의 `._` 파일 제거 | macOS 표준 동작이고 Finder 복사도 같습니다. |
| entitlements에서 `allow-unsigned-executable-memory` 제거 | electron-builder 기본 템플릿과 같은 구성이라 유지했습니다. |
| IPC 보내는 쪽(sender) 검증, 입력 형태 검증 | 다른 보안 조치 후에는 신뢰 경계가 없어 복잡도만 늘어납니다. |
| 미리보기 비동기화·디바운스 | 측정상 영향이 없었습니다(100회 2.5ms). |
| Intel/universal DMG | 요구 사항(Apple Silicon, macOS 12 이상)을 README에 적는 것으로 대신했습니다. |
| DMG 안 앱 이름을 영어로 | 한국어 이름이 의도된 동작이고 README 명령어가 이 이름을 씁니다. |
| appId 변경 | 바꾸면 기존 사용자의 macOS 권한·설정이 초기화됩니다. 정식 서명할 때 함께 검토하세요. |
| 영어 README를 한국어판과 똑같이 | 의도적으로 짧은 문서입니다. 중요한 주의 사항만 맞췄습니다. |
| 임시 파일에 복사 후 이름 바꾸기(복사 중 강제 종료 대비) | 현재 범위를 넘습니다. 나중에 검토할 일로 이 표에 남깁니다. |
| 디스크 이미지(hdiutil)를 쓰는 테스트 | 느리고 환경을 탑니다. `readdirSync` 모의로 같은 경로를 테스트합니다. |

## 사용자 결정 사항

- **버전과 태그** (완료): 이번 변경은 v1.1.0으로 배포했습니다. 이후 릴리스는 `main`에 새 버전을 올리면 CI가 태그와 릴리스를 만듭니다([AGENTS.md](../AGENTS.md)). 기존 `v1.0.0` 태그는 `afd5876`을 가리키지만 배포된 DMG는 `5044478` 직후에 올라갔습니다. 공개된 태그는 옮기지 않습니다.
- **파일 형식 아이콘** (확인됨): `public/file-icons/`의 아이콘은 생성형 AI로 만들었습니다. 일부는 Word·Excel·PDF 등 실제 제품 아이콘과 비슷해 보이므로, 상업적으로 쓰거나 배포 범위를 넓힐 때는 직접 그린 단순한 아이콘으로 바꾸는 것을 고려하세요.
- **LICENSE** (결정됨): 저작권자를 Hyunseop Kim으로 하고, 누구나 사용할 수 있되(학교·회사 포함) 이 프로그램으로 돈을 버는 상업적 이용은 금지하는 비상업 라이선스로 정리했습니다.
- **README 스크린샷**: 실제 앱 화면을 자동 캡처한 뒤 창 테두리를 그려 만든 이미지입니다. 직접 찍은 사진을 원하면 같은 파일명으로 바꾸면 됩니다.
